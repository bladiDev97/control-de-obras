# Reglas de Git

## Mensajes de Commit
- Escribir mensajes de commit en español, claros y descriptivos en tiempo presente/imperativo.
- Ejemplos válidos:
  - `Agregar filtro por estado en módulo de obras`
  - `Corregir validación de columnas en importador de Excel`
  - `Ajustar coordenadas y zoom en vista de mapa`
  - `Actualizar endpoints de contratos en servicios Axios`

## Prácticas
- Realizar commits atómicos que correspondan a una sola funcionalidad o corrección lógica.
- Mantener la rama principal limpia y con compilación (`npm run build`) verificada antes de integrar cambios.
