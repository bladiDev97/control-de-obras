# Módulo: Excel Import

## Propósito
Carga y procesamiento masivo de datos provenientes de plantillas de Excel (`.xlsx`, `.xlsb`), tales como asignaciones, avance de contratos y formatos CFE (SIAD, SENASOL).

## Entradas
- Archivos locales seleccionados o arrastrados por el usuario.

## Salidas
- Previsualización tabular de las filas leídas, detección de discrepancias/errores y confirmación de importación hacia la API.
