# Módulo: Obras

## Propósito
Gestión integral (ABCC: Alta, Baja, Consulta y Cambio) del catálogo y ciclo de vida de obras (pendientes, en proceso, terminadas, asignadas).

## Entradas
- Datos de obras vía API backend (`/obras`).
- Filtros por zona, contratista, estado y fechas.

## Salidas
- Listados paginados y tablas interactivas con estados de obra.
- Formularios de creación y edición de obra.
- Tarjetas resumen y exportación de información.
